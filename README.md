# Divit FPS Payment Gateway for WooCommerce

[![WooCommerce Compatibility](https://img.shields.io/badge/WooCommerce-3.9+-blue.svg)](https://woocommerce.com/)
[![WordPress Compatibility](https://img.shields.io/badge/WordPress-5.3+-blue.svg)](https://wordpress.org/)
[![License](https://img.shields.io/badge/License-GPL%20v2+-green.svg)](LICENSE)

An official WooCommerce payment gateway integration for **FPS by Divit**—the real-time, low-fee, pay-by-bank digital payment solution for modern e-commerce.

---

## ✨ Features

* **Sleek Checkout Integrations**: Fully compatible with both the modern **WooCommerce Blocks-based Checkout** and the classic shortcode-based checkout flow.
* **Instant Payments**: Customers can pay securely in real-time using their preferred local mobile banking apps or by scanning a QR code via the **Faster Payment System (FPS)**.
* **Multi-Mode Support**: Supports **Web-to-App** (mobile redirects) and secure **QR Code payments** on desktop screens.
* **Seamless Refunds**: Processes partial and full refunds directly within the WooCommerce order detail admin panel.
* **Modern WP Compatibility**: Fully optimized for WordPress 6.7+ / 7.0.0+ and compatible with High-Performance Order Storage (HPOS).
* **Cost-Efficient**: Helps merchants save on high credit card processing fees by accepting direct real-time bank transfers.

## 🚀 Installation

You can install the **Divit Payment Gateway** plugin on your WordPress site using one of the following methods:

### Method 1: WordPress Admin Directory (easiest)
1. Log in to your WordPress dashboard.
2. Navigate to **Plugins > Add New**.
3. Search for the keyword **`divit`**.
4. Find the **Divit Payment Gateway** plugin, click **Install Now**, and then **Activate** it.

### Method 2: Manual Download
* Search for the plugin in the [WordPress.org Plugin Directory](https://wordpress.org/plugins/) (search for `divit`) or download from the [WordPress.com Plugins Store](https://wordpress.com/plugins).
* Upload the downloaded ZIP file via **Plugins > Add New > Upload Plugin** on your WordPress admin page and activate it.

## ⚙️ Configuration & Setup

Connect the plugin to your Divit Merchant Account with these simple steps:

1. Log in to your WordPress admin dashboard and go to **WooCommerce > Settings**.
2. Click the **Payments** tab.
3. Locate **divit payment gateway** in the payment methods list and click on it.
4. Set the **Environment** to **Sandbox (for testing)** or **Production** depending on your setup.
5. Retrieve your **API Key** (sent to you by email upon merchant account creation) and input it in the **Api key** field.
6. Click **Save changes**. Once verified, your merchant account details will automatically display at the top of the settings page.

> [!TIP]
> If you don't have an active merchant account yet, you can sign up on our [Merchant Signup Page](https://admin.divit.com.hk/en/signup) or read more details in our [Developer Portal Documentation](https://developer.divit.com.hk/docs/platforms/woocommerce/overview).
